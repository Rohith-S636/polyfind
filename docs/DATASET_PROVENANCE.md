# Dataset Provenance and Validation Report

## 1. Provenance and Licensing

- **Source:** Generated by the PolyFind deterministic catalogue generator in src/catalog/seed.ts.
- **Generation method:** Mulberry32 pseudo-random number generator with an integer seed. The generator defaults to seed 42 and 30 products; the documented demonstration command explicitly requests 50 products.
- **External data:** No retailer feed, retailer API, scraped listing, real seller feed, customer review, or external product dataset is used by this generator.
- **License:** The repository revision reviewed for this report does not contain a root LICENSE file and no separate dataset license was found. This document does not assign CC0 1.0 or MIT to the dataset; neither is asserted as its licence. Confirm the repository's intended code/data licensing before redistribution.
- **Privacy:** Generated records contain no real customer accounts or personal information. Test accounts are disposable fixtures and must not be copied into a real deployment.

The generated product names and descriptions are composed from fixed vocabulary lists and deterministic random choices. They are synthetic examples, not claims about actual brands, products, specifications, availability, or market prices.

## 2. Taxonomy

The generator defines five categories:

| Category ID | Category name | Example vocabulary |
|---|---|---|
| cat-outdoors | Outdoors & Camping | Backpacks, tents, sleeping bags, water bottles, camp stoves, lanterns, trekking poles |
| cat-electronics | Consumer Electronics | Keyboards, mice, monitor hubs, USB-C cables, power banks, webcams, docking stations |
| cat-kitchen | Kitchen & Dining | Chef knives, coffee drippers, burr grinders, skillets, espresso tampers, kettles, cutting boards |
| cat-fitness | Fitness & Exercise | Dumbbell sets, yoga mats, resistance bands, kettlebells, foam rollers, jump ropes, pull-up bars |
| cat-audio | Pro Audio & Headphones | Headphones, microphones, audio interfaces, monitor speakers, IEM earphones, DAC amplifiers |

The generator also selects synthetic brand labels, adjectives and short description fragments from category-specific fixed vocabularies. These are not verified real-world manufacturers or retailer brands.

## 3. Field Distributions and Invariants

| Field | Generator behavior |
|---|---|
| id | Stable identifier prod-0001 through prod-NNNN |
| name | Adjective + product noun + category prefix + generated model number |
| description | One fixed category-specific descriptive fragment plus a generic sentence |
| categoryId | One of the five canonical category IDs |
| price | Numeric value from USD 9.99 to USD 499.99, rounded to two decimal places |
| currency | USD |
| stock | Integer from 0 through 150 |
| availability | in-stock when stock is positive; otherwise out-of-stock |
| brand | Synthetic label selected from the category vocabulary |
| attributes | Simple generated material and finish values |
| dataSource | demo |
| version | 1 for newly generated products |
| updatedAt | Deterministic ISO 8601 UTC timestamp based on the product sequence, starting from 2026-01-01 10:00:00 UTC plus one minute per product |

The generator does not generate live URLs, product images, real retailer prices, user ratings, or external product identifiers.

## 4. Reproducibility

The seed-42 generator returns the same category/product content for the same product count and generator version. Example:

~~~powershell
npm run seed -- --seed=42 --count=50
~~~

The command above is the documented database seed workflow. The lower-level generator itself defaults to 30 products when productCount is omitted; do not confuse that default with the 50-product demonstration/benchmark configuration.

## 5. Integrity Validation Rules

The seed validator checks:
1. unique product IDs and category IDs;
2. every generated product refers to a declared category;
3. finite, non-negative prices;
4. non-negative integer stock;
5. positive integer versions;
6. deterministic generation for a fixed seed and configuration.

MySQL migrations add further database-level constraints and referential integrity. See RELATIONAL_SCHEMA_PHASE4.md.

## 6. Limits and responsible presentation

- The catalogue is synthetic and is not a licensed Indian retailer dataset.
- Prices are generated USD values; do not label them INR or current Indian-market prices.
- Synthetic brand labels are not endorsements or evidence of real manufacturer relationships.
- Product descriptions are generated fixture text, not verified technical specifications.
- A 50-product seed is useful for a deterministic academic demonstration, but it is too small to establish production search performance or external validity.
- Do not use fixture benchmark numbers as empirical results; use the dated raw benchmark artifact and state its commit/environment.
